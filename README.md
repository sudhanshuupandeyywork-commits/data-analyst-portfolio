# Data Analyst Portfolio

Three projects built with SQL, Excel and Power BI. Each one starts from a business question and ends with a recommendation.

| # | Project | Question | Tools | Status |
|---|---------|----------|-------|--------|
| 1 | [Superstore profitability](01-superstore-profitability) | Where is profit leaking, and what do discounts cost? | SQL, Excel, Power BI | Complete: SQL, Excel workbook and findings. Power BI to build |
| 2 | [Budget variance](02-budget-variance) | Where does the overspend come from, and is it persistent? | SQL, Excel, Power BI | Complete: SQL, Excel workbook and findings. Power BI to build |
| 3 | [HR attrition](03-hr-attrition) | Who leaves, and what should we test first? | SQL, Excel, Power BI | Complete: SQL, Excel workbook and findings. Power BI to build |

## How each project is laid out

```
project/
  README.md      the question, findings, recommendation and limits
  data/raw/      untouched source data
  sql/           numbered queries, run in order
  excel/         workbook or build notes
  powerbi/       DAX measures and the page layout
  screenshots/   dashboard images
```

## Notes on the data

- Project 2 uses a simulated ledger, built with a fixed random seed. Real ledgers are confidential. The script that makes it is in the repo.
- Projects 1 and 3 use public practice datasets (Sample Superstore, and IBM's fictional HR dataset). Download them as described in each `data/raw/README.md`.
